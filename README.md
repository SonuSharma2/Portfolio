## 🚀 Key Features

* 🔦 **Interactive Flashlight Spotlight Mask**: Radial gradient cursor-following mask dynamically revealing masked & unmasked superhero identities.
* 🎞️ **Crossed Animated Marquees**: Dual angled 3D marquee strips (`+4deg` & `-4deg`) with interactive physics-based deceleration on hover.
* 🕸️ **Smooth GSAP & ScrollTrigger Animations**: Fluid timeline animations, elastic drops, and responsive coordinate transforms.
* 📱 **100% Responsive Architecture**: Mobile-first responsive hamburger drawer navigation, adaptive grids, and touch-optimized hit areas.
* 📬 **Live Web3Forms Contact Integration**: Real-time asynchronous email delivery directly to inbox with validation and feedback states.
* ⚡ **Ultra-Fast Performance**: Built with Vite, modern React 19, and Tailwind CSS.

## 💻 Local Development Setup

Clone the repository and run locally:

```bash
# 1. Clone repo
git clone https://github.com/SonuSharma2/Portfolio.git

# 2. Navigate into project folder
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

The app will be accessible at: `http://localhost:5173/`
